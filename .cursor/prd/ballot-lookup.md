# 首頁選票查詢：村里

## 決定

首頁在鄉鎮市區之後提供**可略過**的村里選單。

- 不選：里長／村（里）長的「候選人」進該鄉鎮市區全部村里的名單。
- 有選：同一連結加上 `?village=`，名單頁只顯示該村里。名單頁的篩選仍可改回全區。
- 其他職位的候選人連結不因村里選擇而改變。議員選區若依里劃分，仍用既有的「議員選區」選項，與這個村里選單分開。

村里名稱來自 `candidates.json` 的 `village`（村里長的 `district` 是鄉鎮市區）。選單在建置時由候選人資料整理，不另存檔。

## 驗收

- [ ] 選完鄉鎮市區後出現「村里（可略過）」，預設為不指定
- [ ] 不指定時，里長連結沒有 `village` 參數，名單顯示該區各里
- [ ] 指定一里時，里長範圍顯示該里名，連結開啟後只見該里候選人
- [ ] 換縣市或鄉鎮市區會清掉已選村里
