# 候選人列表：縣市與各職位

## 現況（2026-11-16）

`/candidates/` 依直轄市、省轄市、縣列出 22 個縣市。版面與說明頁相同：左側快速導覽，右側為縣市卡片、統計與官方連結。每個縣市顯示該縣市適用的職位與人數，並連到縣市頁 `/candidates/city/{縣市}/`。

縣市頁依縣市類型列出職位：

| 縣市類型 | 職位 |
|----------|------|
| 直轄市 | 直轄市長、直轄市議員、村里長；有山地原住民區時另列區長、區民代表 |
| 省轄市 | 縣（市）長、縣（市）議員、村里長 |
| 縣 | 縣（市）長、縣（市）議員、鄉鎮市長、鄉鎮市民代表、村里長 |

市長在縣市頁直接列出姓名。議員、鄉鎮市區、村里長先依選區或行政區連結到既有名單頁 `/candidates/district/{職位}/{縣市}/…`。名單頁頂端可切換同縣市其他職位。

議員名單的路徑用選區簡稱，例如 `/candidates/district/councilor-municipal/臺北市/第5選舉區/`。官方全名（`臺北市第5選舉區`）會轉到這個簡稱頁。候選人詳細頁的選區連結也指向簡稱頁。

村里長仍只提供列表，不生成個別詳細頁。
