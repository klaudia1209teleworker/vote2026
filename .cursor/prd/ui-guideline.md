# 全站 UI：黑白灰階

## 狀態（2026-11-16）

視覺依 `TAIWAN_ELECTION_2026_UI_GUIDELINE.md` v1.0（Neutral Monochrome）。實作留在 Astro 靜態站，token 寫在 `src/styles/global.css`。

### 已套用

- 背景 `#FAFAF9`、卡片 `#FFFFFF`、文字 `#202124`、主按鈕 `#111111`
- 既有藍、綠、紅、琥珀、紫、teal、primary 色階改對應到灰階，避免品牌色殘留
- 內容寬度最大 1440px；手機左右 16px、平板 24px、桌機 32px
- 頁首：站名「2026 台灣九合一地方選舉資訊彙整」，手機與桌機同一句。現有頁面導覽。桌機 Active 為黑字與底線；說明頁目前項目與手機導覽列改用左側 4px 直線。手機導覽為頁首下方可橫向滑動的一列，含查詢選票
- 首頁順序：全屏滿版 Hero（風景背景 `cover`；標題、說明、選舉摘要直接疊在圖上，查詢選票維持自己的白卡片）、快捷入口、選舉時程與投票指南同一列（寬螢幕左時程、右指南；窄螢幕時程在上）、YouTube 致敬、官方連結。Hero 圖是 `public/hero-landscape.webp`，貼齊導覽列下緣。未查詢時圖片只顯示與內容同高的上半部；按下查詢、結果出現後，Hero 拉高到圖片 16:9 以顯示全圖。圖上覆一層 `rgba(32, 33, 36, 0.55)` 深灰透明遮罩，標題與摘要為淺色。手機專用 Hero 圖尚未提供，先與桌面共用同一張
- 主按鈕、輸入框、徽章、焦點框與觸控高度對齊規範
- YouTube 使用既有讀字生活 Ep02（`f6VOJumCwIg`）。首頁預先連線並直接嵌入 `youtube-nocookie.com`，不等待點擊
- 頁尾為單欄：標題「資料來源（資料更新 2026-11-15｜來源清單與免責說明）」，其下一段為官方公告與 YouTube 免責
- 全站右下角固定黑色懸浮按鈕「勘誤建議回報」。點開後選擇勘誤或建議，以電子郵件送出，主旨分別為 `[勘誤]`、`[建議]`，並帶入目前頁面網址。候選人頁與選區頁不再另放「回報資料錯誤」文字連結
- 首頁與共用卡片、頁首、頁尾的間距比規範建議值更緊，觸控目標仍維持按鈕至少 44px
- 說明頁（職務介紹、職務詳細、判斷候選人、投票指南、合作案例、關於）與候選人列表 `/candidates/` 使用全寬內容區：左側為快速導覽，右側為分區卡片。職務詳細頁左側另列其他職務。不再把這些頁縮在 960px。候選人列表以縣市卡片列出職位與人數，不使用表情符號或色塊提示

### 刻意不做

- 不改成 React／Next.js，不新建規範第 12 節的目錄
- 頁面不放開票結果區塊或「尚未公布」狀態
- 不畫可點的台灣縣市地圖。首頁不放縣市清單與候選人區塊；依縣市查看仍在候選人頁。Hero 風景圖裡的台灣輪廓是背景插畫，不是選區導覽
- 不加政黨色點。規範要求政黨色須有查證過的資料字典，本站目前只有政黨名稱文字
- 不把示意數字、假候選人寫進正式頁。統計只用既有 `districts.json`、`positions.json`、`candidates.json`
- 不改候選人資料、政見與現任表現的計算方式
